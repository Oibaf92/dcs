# DCS

Script e strumenti per DCS World.

| Cartella | Contenuto |
|---|---|
| [`iads/`](iads/README.md) | rete di difesa aerea integrata (IADS) "senza onniscienza": SAM a radar spento che si accendono solo sui bersagli rilevati dalla rete |
| [`tts/`](tts/README.md) | voci radio sintetiche (AWACS, gregari, JTAC, torre): testo → voce Piper offline con effetto radio → `.ogg` per i trigger e gli script DCS |
